# Python のみち

ブラウザだけで Python を学べる練習サイトです。インストールもアカウントも要りません。

**https://fatcorn753.github.io/py-michi/**

## 特徴

- **1 行ずつ実行して、名前とオブジェクトの関係を見る。** 変数の名前からオブジェクトへの矢印、リストや辞書の中身、関数の呼び出しの積み重なりを、行ごとに図で示します。同じリストを 2 つの名前が指している様子も、矢印で分かります。
- **本物の Python がブラウザの中で動く。** [Pyodide](https://pyodide.org/)(WebAssembly 版の CPython)を Web Worker で動かしています。止まらないループは、一定の行数か 5 秒で止めます。
- **読む → 予測する → 書く の順に練習する。** 例題、出力の予測、トレース表、行の並べ替え、穴埋め、白紙から書く問題を、単元ごとにこの順で解きます。
- **身に付いたかを測る。** 最初の診断テストで出発点を決め、確認テストに合格すると次の単元が開きます。忘れかけたころに、数字を変えた問題で復習します。
- **作るものに向かうコース。** 本編のほかに、入力欄とボタンのある「家計簿アプリ」と、文章の単語を数えて多い順に並べる「テキスト集計ツール」を作る作品コースがあります。家計簿アプリは、Streamlit に似た小さな道具 `ui` で画面を組み立て、操作をなぞった後の画面で採点します。

記録はブラウザの中(localStorage)にだけ保存されます。

## 内容

| コース | 単元 |
|---|---|
| 本編: Python の基礎 | 値と計算 / 条件分岐 / 繰り返し / リストと文字列 / 関数 / 名前とオブジェクト |
| 作品: 家計簿アプリ | 画面に出す / 入力とボタン(続きを作成中) |
| 作品: テキスト集計ツール | 文章を単語に分ける / 辞書で数える / 多い順に並べて表にする |

## 制限

- `input()` は、実行の前に入力欄へ書いた行を順に返します。実行の途中で入力を待つことはできません。
- 初回は Pyodide(約 10 MB)を CDN から読み込むため、少し時間がかかります。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npx vitest run   # 実行環境と全教材の検査(Node 版 Pyodide で動かす)
npm run build
```

- `src/py/` — Pyodide の Worker、`sys.settrace` による 1 行ごとの記録、実行の管理
- `src/content/` — 教材。正解の出力は書かず、参照解を実行して求めます
- `src/learn/` — 習得度の推定(BKT)、復習の予定、採点、記録
- `src/ui/` — 画面
