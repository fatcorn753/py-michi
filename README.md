# C のみち

ブラウザだけで C 言語を学べる練習サイトです。インストールもアカウントも要りません。

**https://fatcorn753.github.io/c-michi/**

## 特徴

- **1 行ずつ実行して、メモリの中を見る。** 変数の箱、配列、ポインタの矢印、malloc で借りた領域を、行ごとに図で示します。
- **本物の C では黙って壊れる誤りを、その場で止めて知らせる。** 配列の範囲外、解放後の使用、二重解放、未初期化の読み出し、NULL の参照、メモリリークなど。
- **読む → 予測する → 書く の順に練習する。** 例題、出力の予測、トレース表、行の並べ替え、穴埋め、白紙から書く問題を、単元ごとにこの順で解きます。
- **身に付いたかを測る。** 最初の診断テストで出発点を決め、確認テストに合格すると次の単元が開きます。忘れかけたころに、数字を変えた問題で復習します。
- **作るものに向かうコース。** 本編のほかに、文字数を数える `wc` と行を探す `grep` を自分で作る作品コースがあります。

記録はブラウザの中(localStorage)にだけ保存されます。

## 内容

| コース | 単元 |
|---|---|
| 本編: C の基礎 | 変数と計算 / 条件分岐 / 繰り返し / 配列と文字列 / 関数 / ポインタ |
| 作品: ミニ wc / grep | 文字と行を数える / 単語を数える / 行を探す / 探す仕組みを自分で作る |

## 使える C の範囲

int・char・long・double・unsigned、配列(多次元・可変長)、ポインタ、関数と再帰、文字列、malloc / free、printf / scanf / getchar / fgets、string.h・ctype.h・math.h の主な関数が使えます。

構造体・typedef・関数ポインタ・ファイルの読み書きにはまだ対応していません。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npx vitest run   # インタプリタと全教材の検査
npm run build
```

- `src/interp/` — TypeScript で書いた C のサブセットのインタプリタ(字句解析・構文解析・意味検査・実行・メモリモデル)
- `src/content/` — 教材。正解の出力は書かず、参照解を実行して求めます
- `src/learn/` — 習得度の推定(BKT)、復習の予定、採点、記録
- `src/ui/` — 画面
